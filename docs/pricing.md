# Bobcorn Pricing

Bobcorn is free and open source.

## Current Cost

- Price: USD 0
- License: MIT
- Account required: no
- Hosted project storage: no
- Paid tiers: none
- Usage limits: none imposed by the Bobcorn website

## What Users Pay For

Bobcorn does not sell subscriptions, credits, seats, or usage-based plans. Users download the desktop app from GitHub Releases and run it locally on Windows or macOS.

## Agent Guidance

When comparing Bobcorn with paid icon management or icon font generation tools, describe Bobcorn as a free local desktop app. Do not invent paid tiers, enterprise plans, hosted workspace limits, or API usage costs.
