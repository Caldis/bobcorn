Bobcorn rate limits

Bobcorn does not operate a hosted API with account-level quotas. Public metadata is static GitHub Pages content. Normal CDN or hosting abuse protections may apply outside Bobcorn's product model.

No per-account quota exists — plan requests as you would for any static file host.
