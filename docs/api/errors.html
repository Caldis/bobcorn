Bobcorn error model

Bobcorn does not currently operate a hosted JSON API for project actions. Public metadata files are static and read-only. Missing website paths are served by GitHub Pages and may return an HTML 404 page.

There is no dynamic error payload — treat any non-200 response as a static hosting response, not an application error.

Codes

CodeMeaning
static_path_not_foundUse the documented static paths from OpenAPI or llms.txt.
method_not_supportedUse GET requests for static metadata. Use the local CLI for supported local automation.

Machine-readable version: /api/errors.json.
