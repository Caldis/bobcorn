Bobcorn Error Model

Bobcorn does not currently operate a hosted JSON API for project actions. Public metadata files are static and read-only. Missing website paths are served by GitHub Pages and may return an HTML 404 page.

  • static_path_not_found: use the documented static paths from OpenAPI or llms.txt.
  • method_not_supported: use GET requests for static metadata. Use the local CLI for supported local automation.

Machine-readable version: /api/errors.json.
