Bobcorn MCP Status

Bobcorn does not currently publish a hosted MCP server. This page documents that boundary so agents do not try to open a non-existent MCP transport.

Supported Alternatives

  • Use the local CLI for supported `.icp` project automation.
  • Use OpenAPI for read-only public website metadata.
  • Use the A2A agent card for capability discovery.
