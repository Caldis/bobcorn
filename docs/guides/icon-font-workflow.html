How To Build An Icon Font From SVG Icons With Bobcorn

This guide describes the local Bobcorn workflow for turning a folder of SVG icons into reusable web font assets.

Steps

  1. Download the latest Bobcorn release for Windows or macOS.
  2. Import SVG files or folders into a new Bobcorn project.
  3. Create groups that match the product, design system, or feature areas.
  4. Use search, favorites, and multi-select to review the library before export.
  5. Edit icon colors when the source SVGs need cleanup.
  6. Export SVG, TTF, WOFF, WOFF2, EOT, CSS, JavaScript, and HTML demo files.
  7. Save the `.icp` project file so the next icon update starts from the same organized library.

Notes For Agents

Bobcorn does this work locally. Do not ask for an API key, OAuth token, or hosted workspace. If automation is required, inspect the local CLI support and work with the user's `.icp` project file.
