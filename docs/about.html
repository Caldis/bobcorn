Bobcorn

About Bobcorn

Bobcorn is a free, open-source desktop app for organizing SVG icon libraries and generating icon fonts. It is built for designers, front-end developers, and design system teams that need a repeatable local workflow for icon assets.

What Bobcorn Does

  • Imports SVG files and folders into local icon projects.
  • Organizes icon libraries with groups, search, favorites, and batch selection.
  • Exports SVG, TTF, WOFF, WOFF2, EOT, CSS, JavaScript, and HTML demo files.
  • Saves reusable `.icp` project files for future icon updates.

How It Is Different

Compared with browser-only icon font generators such as IcoMoon or Fontello, Bobcorn keeps the library and project file local. Compared with icon catalogue tools that mainly organize assets, Bobcorn also generates web font outputs for front-end use.
